About

Attention Feed is a collection of software experiments and tools by me (Alexander Macgillivray, though many call me amac). Some are live and in use, others are works in progress.

The projects in Attention Feed started as [a way to learn more about the various LLM coding agents](https://www.bricoleur.org/search/label/ai-coding), but in building to learn there were also some things that were good enough to be worth sharing with others.

I also have a blog at bricoleur.org.
