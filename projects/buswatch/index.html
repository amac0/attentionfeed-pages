BusWatch

● live

BusWatch gives real-time London, England bus times based on your location It’s a WearOS app built for the Pixel and other WearOS watches that shows you when the next bus is coming, right from the wonderful Transport for London API.

How It Works

Open the app and it finds the five closest bus stops within 500 meters using your location. Tap a stop to see live arrival times for every route that serves it. That’s it: no searching, no typing, no menus. BusWatch uses your location to query the Transport for London API but does not share the location with Attention Feed or others.

What You See

Nearby stops: a scrollable list of the closest bus stops, sorted by distance, each showing its stop code and name.

Arrival times: tap a stop to see all incoming buses sorted by arrival time.

Feedback

BusWatch is a work in progress. If you have feedback, suggestions, or run into issues, send an email to attnfeed@gmail.com.
